# VWAP 지표 적용 검토 + Edge AI 실제 익절/손절 재검증 (2026-11-26)

사용자 요청(2026-11-26)
1. Edge AI 를 실제 익절/손절 값(익절 3% / 손절 1.27% / 300분)에 맞춰 다시 검증.
2. Edge AI 모델 설계를 손봐야 하는지.
3. "분봉/일봉이 VWAP 위에서 유지되면 우상향, 아래면 우하향" - 규칙 매매와 반등 감시 알림에 VWAP 을 적용할지 검토.

모든 실험은 읽기 전용이다(주문 없음, 봇 설정/게시 모델 변경 없음, 산출물은 runtime 밖 임시 폴더).
데이터: g001 1분봉 101거래일(2026-06-29 ~ 11-26), 유동성 필터(20일 평균 거래대금 30억 이상, 하루 150종목 표본).

## 1. Edge AI: 실제 익절/손절 기준 재검증

방법: g013 을 `--tp 3 --sl 1.27 --horizon 300` 으로 다시 만들고(이벤트 410,270건), g014 워크포워드(14구간)를 `--no-publish` 로 실행.

| 라벨 / 학습 대상 | OOS AUC | 전체 평균 순손익 | 모델이 고른 것 | 승격 |
|---|---|---|---|---|
| 현행: 익절 2 / 손절 1.77 / 400분, y_tp | 0.711 | -0.604% | -0.611% (56,325건) | 탈락 |

- 모델이 맞히는 것은 "방향"이 아니라 "변동성과 남은 시간"이다(중요도 상위: minutes_since_open, bb_width_pct, d_atr_pct, atr_pct).
- "순손익 > 0" 을 직접 맞히게 하면 AUC 0.516 - 지금 피처로는 방향을 못 맞힌다.

손익 분해(실제 라벨, 이벤트 평균):

| 항목 | 값 |
|---|---|
| 비용 전 가격 움직임 | 약 -0.08% |
| 슬리피지(진입/청산 각 1틱, 틱 크기 평균 0.133%) | 약 -0.27% |
| 수수료 + 매도세 | -0.23% |
| 순손익 | -0.574% |

결론: 익절/손절 값을 실제에 맞춰도 결과는 같다. 문제는 청산 값이 아니라, 후보(규칙 트리거 이벤트) 자체에 비용 전 우위가 없고
(-0.08%), 왕복 비용 약 0.5%를 그대로 잃는 구조라는 점이다.

## 2. Edge AI 모델 설계에서 손봐야 할 것

1. 학습 대상: y_tp(손절 전 +tp% 도달)는 변동성이 큰 종목/이른 시간을 고르면 올라가는 값이다. 손절 확률이 같이 오르므로 기대값과 무관.
   -> 대상은 실제 청산 규칙의 순손익(회귀 또는 순손익 > 비용 여유)로 하고, 장벽은 % 고정이 아니라 ATR 배수로 맞춘다.
2. 기준값: 지금은 "최소 20% 는 남긴다(min_keep)" 안에서 정밀도가 가장 높은 값을 고른다. 손익분기 확률
   (익절 3 / 손절 1.27 기준 약 36%, 익절 2 / 손절 1.77 기준 약 54%)과 무관하게 정해져서, 기준값 0.33 은 구조적으로 음의 기대값이다.
   -> 기준값은 "검증 구간 기대 순손익 > 0" 일 때만 존재하게 하고, 없으면 그날은 아무것도 사지 않는다(0건 허용).
3. 승격 전 모델의 사용: Edge AI 매매(실제/가상)는 승격 여부와 무관하게 최신 모델의 기준값으로 산다. 승격 심사를 통과한 적이 없는 모델이
   실제 주문에 쓰였다. -> Edge 실제 매매는 승격된 모델에서만 허용.
4. 후보군: 규칙 트리거(1분 BB 중심선 위 + 교차/상승) 이벤트는 30 / 60분 뒤 평균이 -0.16%. 걸러낼 대상에 우위가 없으면 필터는 소용없다.
   -> 후보 정의 자체를 바꿔야 한다(예: 일봉 추세 + 눌림 후 재돌파, 거래대금 급증 첫 봉 등 비용을 넘는 가설을 먼저 사건 연구로 확인).
5. 비용: 틱 크기 0.2% 이상인 종목은 평균 -0.81%(0.05 ~ 0.1% 는 -0.43%). 호가 단위가 큰 가격대는 후보에서 뺀다.
6. 학습/실전 차이: 실전 신호 9일(1,284건) AUC 0.635 < OOS 0.711, trig_path 분포 차이 큼 - 데이터셋 이벤트와 실전 트리거가 다르다.

## 3. VWAP 검증 (g054_vwap_study.py)

VWAP = 당일 누적(종가 x 거래량) / 누적 거래량 (g013, 앱 차트와 같은 계산).

왜 오르는 날은 VWAP 이 봉 아래에 있나: VWAP 은 그날 지나온 가격의 거래량 가중 평균이다. 가격이 계속 오르면 평균은 현재가보다 낮고,
계속 내리면 평균이 현재가보다 높다. 즉 위/아래 위치는 "오늘 지금까지 올랐다/내렸다"를 다시 그린 것(결과)이다.
"벽"처럼 보이는 것은 대부분 이 산술 때문이다. 쓸모가 있으려면 "지금까지 오른 것"을 빼고도 "앞으로"를 맞혀야 한다.

### 3-1. 무조건부 (347,314 표본, 10분 간격 09:30 ~ 14:10)

상태: above_30m = 최근 30분 종가가 전부 VWAP 위, below_30m = 전부 아래. 초과 수익 = 같은 시각 전 종목 평균을 뺀 값.

| 위 유지 | 86,323 | +0.005% | +0.016% | +0.021% |
| 아래 유지 | 126,012 | +0.000% | +0.001% | +0.003% |
| 차이(위 - 아래), 일 단위 부트스트랩 95% | | +0.004 [-0.015, +0.024] | +0.015 [-0.019, +0.051] | +0.019 [-0.069, +0.107] |

- 차이 없음(신뢰구간이 0 을 포함, 크기도 비용 0.5% 의 1/30).
- VWAP 대비 +2% 초과는 오히려 이후 -0.08 ~ -0.20% (이미 있는 추격 차단 ANTI_CHASE_MAX_VWAP_GAP_PCT = 3% 와 같은 방향).
- VWAP 기울기, 세션 중 위에 있던 비율, 교차 횟수: 모두 ±0.04% 이내.
- 예외: 시가 대비 가장 많이 내린 5분위(평균 -4.4%) 안에서 "위 유지 - 아래 유지" 의 15:15 까지 초과 수익 차이가 +0.39%p
  [+0.17, +0.64] (위 유지 표본 4,051개, 같은 종목의 반복 표본 포함). 급락 후 VWAP 을 되찾은 종목. 수익률 자체가 아니라 두 집단의
  차이이고, 5분위 x 3기간 x 여러 지표를 본 뒤 나온 값이라 가설 수준이다(다중 비교 미보정). 비용(0.5%)보다도 작다.
- 일봉: 종가가 당일 VWAP 위인 날 - 아래인 날의 다음 날 수익 차이 -0.06% [-0.40, +0.29] (n = 2,828). 차이 없음.

## 4. 적용 의견 (Codex 검토 전 초안)

- 규칙 매매: VWAP 조건을 매수 차단/허용 조건으로 추가하지 않는다(효과 0, 이미 점수와 추격 차단에 들어 있음).
- 반등 알림: 차단 조건으로 쓰지 않는다. 알림에 "VWAP 위/아래 + 유지 시간"을 정보로 표시하는 것은 가능(주문과 무관한 표시).
  검토할 만한 것은 "급락 종목이 VWAP 을 되찾아 30분 유지"(3-1 의 예외) 를 별도 알림 종류로 관찰하는 것 - 먼저 로그로만.
- Edge AI: 실제 매매는 계속 끄고, 2장의 1 ~ 4 를 설계 변경 대상으로 한다.

## 5. Codex 검토 (2026-11-26, 비판적 검토 요청, 읽기 전용)

판정

| 항목 | 판정 | 이유 |
|---|---|---|
| (a) VWAP 을 규칙 매수 조건으로 | 기각 | 기존 VWAP 점수 / 추격 차단에 위치 필터를 더할 순손익 근거가 없음 |
| (b) VWAP 을 반등 알림 조건으로 | 보류 | "첫 재돌파 / 유지 확인" 을 별도 로그로 검증할 가치는 있음 |
| (c) 알림에 정보로 표시 | 채택 | VWAP 대비 괴리율과 연속 유지 시간 표시 |
| (d) Edge AI 재설계 | 수정 후 채택 | 승격 통제 먼저 -> 실전 재현 -> 순손익 목표 / 0건 허용 -> 후보군 검증 순 |

지적 사항(이 문서의 한계로 받아들임)
- 표본 편향: 3-1 과 일봉 표본은 "그날 트리거가 한 번이라도 나온 종목"만 쓴다(오후 트리거가 오전 표본 포함 여부를 정함). 일봉은 다음 날에도
  표본에 든 종목만 남는다(n = 2,828). 전일 확정 유니버스로 다시 만들어야 "효과 없음"을 일반화할 수 있다.
- VWAP 정의: 분봉 종가 x 거래량은 분 안의 체결가를 종가로 대신한다. 거래대금 / 거래량으로 교차 확인 필요. 빠진 분봉이 있으면 "30분"이
  아니라 "30개 봉"이다.
- 수익 기준: 3-1 은 신호 봉 종가를 진입가로 쓴다(체결 가능 가격 아님). 초과 수익은 날짜 / 시각 비중 차이가 남을 수 있어 원수익과 같이 봐야 한다.
- 3-1 의 예외(+0.39%p)는 문서 초안이 수익률처럼 적었으나 두 집단의 차이다(본문 수정함). 새 거래일에 사전에 정한 규칙으로, 종목당 하루 첫
  확인만, 시각 / 낙폭 / 직전 반등폭을 맞춘 대조군과, 다음 봉 체결 + 비용 후 수익으로 검증해야 한다.
- Edge AI: y_tp 는 300봉 제한 없이 15:15 까지 보는 별도 경로라 실제 청산과 다르다. 먼저 실전 후보 / 피처 / 청산 / 체결을 재생해 라벨을
  맞춘 뒤 순손익 회귀나 "청산별 확률 x 손익" 으로 비교할 것. ATR 장벽은 청산 규칙 자체를 바꾸는 별도 실험이다.
- "후보군에 우위가 없다" 는 전체 평균에 대한 말이다. 수익이 나는 부분집합이 없다는 증명은 아니고, 시험한 모델이 찾지 못했다는 것까지가 사실이다.
  호가 단위가 큰 종목 제외도 가격대 / 유동성을 맞춘 뒤 판단할 것.

추가로 검증할 가치가 있다고 본 것(2개): (1) 급락 후 첫 VWAP 재돌파와 30분 유지 확인을 사건 시점으로 검증, (2) 돌파 후 VWAP 첫 눌림 /
재상승을 같은 시간대 / 변동성의 일반 눌림과 비교. 표준편차 밴드, 다일 / 앵커 VWAP, 볼륨 프로파일은 후순위.

## 6. 정리

- 규칙 매매에 VWAP 조건 추가: 하지 않는다.
- 반등 알림: 조건으로는 보류, 정보 표시는 채택(알림 내용에 VWAP 대비 %, 연속 유지 시간). "급락 후 VWAP 재돌파 유지" 는 로그로만 먼저 검증.
- Edge AI: 실제 매매는 꺼 둔다. 설계 변경 순서는 Codex 의견대로 (1) Edge 실제 주문은 승격된 모델에서만, (2) 실전 재현 라벨,
  (3) 순손익 목표 + 기준값 없으면 0건, (4) 후보군 재정의.
