### 1-2. 데이터 갱신 주기 및 확정봉/미확정봉

- 1분봉 1회 조회(약 30행)로 3분봉/1분봉을 따로 만들고 200봉 캐시에 병합합니다. 3분봉은 20초마다, 1분봉은 봉 경계에 갱신합니다.
- 확정봉 필터 `index <= floor(now-2s)`는 정상입니다. **3분봉에는 봉 경계 갱신이 없어** 최대 20초 늦은 프레임으로 판단할 수 있습니다.
- **매수에는 미확정 3분봉이 쓰입니다**(`ENABLE_INTRABAR_LIVE_ENTRY_FILTER=True`). 이 봉의 시가는 봇이 처음 본 가격이고, **거래량은 직전 봉 값을 복사**합니다(r003 `_build_realtime_entry_frame`). 그래서 거래량 계열 지표(MFI, OBV, VWAP, 거래량비)가 왜곡됩니다.
- VWAP는 캐시 첫 봉 기준 누적이라, 12:20 이후 200봉 캡에 걸리면 기준점이 이동합니다. 장중 재시작하면 30분치로 시작합니다.

### V2 전략 규칙 (요약)

1. **일봉(D-1 확정봉만)**: 종가 > MA20 > MA60, MA20 5일 기울기 ≥ 0, MA60 20일 기울기 ≥ -1%, MA20 대비 +15% 이내, 20일 평균 대금 ≥ 30억, ATR 1.5~12%, 호가단위/가격 ≤ 0.3%. 점수 상위 40종목.
2. **5분 컨텍스트(완성된 5분 버킷만)**: EMA20 상승(3봉 전 대비), 세션 VWAP(거래대금 누적/거래량 누적).
3. **셋업 1 – 눌림목**: 장중 고점이 VWAP + 1 ATR5m 이상(임펄스) → 1분 저가가 max(EMA20, VWAP) + 0.25% 안으로 진입 → 깊이 0.5~3 ATR → 30분 안에 트리거.
4. **셋업 2 – 돌파 후 재진입**: 09:00~09:30 고가 = 기준선 → 5분 종가가 기준선 +0.1% 위 & 거래량 1.5배 이상(돌파) → 기준선 +0.4% 안으로 되돌림(저가·종가 모두 -0.5% 이탈 금지) → 트리거. **추격 매수 없음.**
5. **1분 트리거**: 양봉, 지지선 위 종가, 직전 1분 고가 돌파, 거래량 ≥ 직전 20봉 평균 x 1.3, 봉 상승폭 ≤ 1.5%, 지지선 대비 +1.5% 이내.
6. **청산(포지션별 독립 상태)**: 같은 봉에서 손절을 익절보다 먼저 확인(보수적), 갭으로 손절선 아래에서 시작하면 시가로 체결.

| 체결 횟수 vs 체결량 | 틱봉은 **체결 횟수(건)** 기준으로 경계를 정합니다. 체결량(주)은 별도로 집계합니다(매수/매도 주도 거래량 분리) |
| 누락·중복·순서 역전 | 건별 시퀀스 번호가 없어서 **누적거래량과 누적 체결건수로 무결성을 판정**합니다. 같으면 중복, 작으면 순서 역전(폐기), 건수가 점프하면 정확한 누락 수, 거래량만 점프하면 건수를 모르는 누락(정렬 불확실). **봉 경계는 거래소 체결번호 기준 절대 정렬**((k-1)//N)이라 누락이 이후 경계를 밀지 않습니다. 불확실한 봉은 invalid로 표시해 필터 판단에서 제외하고, 가용 시각은 수신 시각(recv_ts) 기준입니다 |
| KIS 샘플 라이브러리 이슈 | `KISWebSocket`이 다건 프레임(`0\|H0STCNT0\|003\|...`)을 pandas로 1행 처리해 **틱이 누락되거나 뒤섞일 수 있음** → 수집기는 원문을 직접 분할합니다 |
| 120틱 보조 필터 | 최근 5개 틱봉 중 상승 3개 이상, 매수 주도 거래량 55% 이상, 순상승, 무효 봉·누락·정체 시 기권(진입 차단). 신호 확정 **전에** 적용하므로, 거절돼도 셋업은 유지됩니다 |
| 성능 비교 | g012가 같은 날 같은 종목 집합에서 A_T(=A, 틱 수집 종목 한정) / B / C를 비교하도록 구현했습니다. **데이터가 없어 결과 없음** |

**확인이 필요한 가정**: `SELN_CNTG_CSNU + SHNU_CNTG_CSNU`가 세션 누적 체결 건수인지 실데이터로 검증해야 합니다. 맞지 않으면 엔진이 자동으로 거래량 기반 판정으로 내려갑니다.
