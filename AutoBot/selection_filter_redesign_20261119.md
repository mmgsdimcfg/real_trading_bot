2. **최종 단계를 좁히는 것은 유동성과 장중 ATR**이다. 상승 초입 패턴 A/B 등급은 하루 87종목이 나오지만 77.5종목이 유동성 미달

3. **레거시 추세 하드필터 5개(down_trend, flat_trend, box_range_no_progress, bearish_candle_dominant, linreg_long_term_downtrend)는

5. **점수에서 같은 사실을 여러 번 감점**한다. 예: 52주 고가 근접(플래그 -0.7 + 별도 감점 6~12), 전일 급등(플래그 + 갭 감점 4~10

## 1. 현재 선정 흐름 (적용 순서)

```
scan()
 ├ 종목별 evaluate_candidate()  (병렬)
 │   Stage 0  skip_reason: 상장일수 부족 / 거래량·거래대금 0          -> 평가 중단(집계에서 빠짐)
 │   지표 계산 (ATR14, MA5/20/60, RSI10, 52주 고저, 추세 상태 ...)
 │   하드필터 -> fail_reasons  (아래 순서, 단락 없이 전부 검사)
 │     패턴(_pattern_assessment, 내부는 단락 평가) / 가격대 / 우선주·스팩 / 파생 ETF / 관리·정지
 │     down_trend, flat_trend, box_range, bearish_dominant  (반전 신호면 *_reversal_override 플래그로)
 │     linreg 장기하락 / 상한가 후 급락 / 장대음봉 2%
 │   소프트 플래그 (추세 9종, 과매수 3종, 거래량, 변동성, 52주 위치 4종, 갭)
 │   패턴 A/B면 레거시 5개 fail -> *_pattern_override 플래그로 전환
 │   1차 점수, low_score
 │   패턴 A/B 종목만 장중 지표(VWAP, 3분봉 ATR) 읽기 -> low_intraday_atr / intraday_atr_unknown
 ├ 장중 ATR 필터 일괄 해제(전 종목 데이터 부재일 때만)
 ├ 시장상대 유동성 필터 (시장 평균 거래대금 x 0.7, 거래량·거래대금 둘 다 미달이면 fail, 200억+ / 패턴 50억+ 면제)
 ├ 전 종목 재채점 (최종 점수, low_score)
 ├ 적격(fail 없음) 정렬: 등급 -> 점수 -> 거래대금 -> ATR, 동점 경계만 무작위
 ├ 보충: 적격이 max_picks 미만이면 trend_state=up(또는 near-miss) + relaxable 사유만 + 이격 10% 이내 + 점수 + 장중 ATR
 └ 업종 쏠림 교체, 최종 정렬
```

확인 사항:
- **하드필터는 점수 계산 전에 종목을 제거하는가** - 그렇다. 점수는 탈락과 무관하게 계산되지만 적격 = `fail_reasons` 없음이고,
  점수는 적격 종목끼리의 순서와 `low_score` 바닥선에만 쓰인다. 보충만 점수로 탈락 종목 일부를 되살린다.
- **집계 왜곡 2가지**: (1) `_pattern_assessment`는 단락 평가라 `pattern_no_bullish_close`, `pattern_bearish_candles`,
  `pattern_b_extended`, `pattern_few_buy_signals`는 다른 패턴 조건을 모두 통과한 종목에서만 집계된다(실제 발생보다 적게 보임).
  (2) 장중 ATR은 패턴 통과 종목과 보충 후보만 읽어 `low_intraday_atr`도 그 집합 안의 수치다.
  필터별 "단독 탈락 수 = 그 필터만 풀면 추가 통과 수"는 이 두 가지 때문에 근사치다(정확한 값은 7장 실험에서 재스캔으로 구한다).

## 4. 충돌과 도달 불가 경로

1. **레거시 하드필터 5개는 단독 탈락 0건** (3장 H22~H26). 패턴 통과 종목에서는 경고로 바뀌므로, 패턴이 필수인 한 적격 판정에 영향이 없다.
   남은 효과는 (a) 보충 자격 차단(거래 가능 종목군 하루 205.6종목), (b) `*_reversal_override` -1.5 감점뿐이다.
2. **H18 약한 마감의 꼬리 예외가 H20 때문에 도달 불가**: 몸통 2% 이상 + 아래꼬리 >= 몸통인 음봉은 패턴에서 통과하지만 H20에서 탈락한다.
3. **보충 near-miss의 추세 면제가 거의 동작하지 않음**: near-miss 종목은 `trend_state=up` 요구를 면제받지만, 하락/횡보 종목은 대개
   down_trend/flat_trend 하드 사유가 함께 있어 `_fallback_relaxable_row`(추가 사유가 전부 pattern_*여야 함)에서 막힌다.
   25일 보충 선정 145건 중 trend_state가 up이 아닌 것은 5건.
4. **유동성 면제 표시가 감점됨**: `liquidity_below_market_dual_pattern_exempt` / `_but_absolute_safe`는 "충분히 유동적이라 면제"라는 뜻인데
   플래그 개수 감점(-0.7)을 받는다. `intraday_atr_filter_disabled_no_data`(데이터 부재 표시)도 같다.
5. **RSI 정의 2개**: 점수와 rsi_overbought는 RSI(10, g002 계산), 패턴 과열(H16)과 매수 신호는 g001 daily.csv의 RSI.
   같은 종목에서 두 값이 다르다.
6. **"패턴 필수"와 보충의 충돌**: 보충은 pattern_* 탈락을 구제하므로(이격 10% 이내) 선정의 63%가 패턴 미통과 종목이다.
   어느 전략으로 뽑혔는지 결과에 남지 않는다.
7. **시장상대 유동성 기준이 그날 평가 종목 구성에 의존**: 11/18처럼 수집이 덜 된 날은 평균이 바뀌어 같은 종목의 통과 여부가 달라진다
   (속도 개선 비교에서 보충 1종목 차이로 확인).

## 6. 개선 설계

### 6.1 3단계 구조

```
1단계 필수 (거래 가능 여부)  - 모든 전략 공통, 하드
   데이터 완전성: 대상일 10초 파일 + daily.csv(대상일 행, 25행 이상)
   구조적 배제: 가격대(2,000원~100만원), 우선주/스팩, 파생 ETF, 관리/정지, 상한가 후 급락
   유동성: 20일 평균 거래대금 >= 50억 (현재 면제/보충 하한과 같은 값 - 새 문턱 아님)
   실행 적합성: 장중 3분봉 ATR 중앙값 >= 0.40%  (전 종목 계산 - 현재는 패턴 통과 종목만)
2단계 전략 분류 (종목당 0~3개 전략 태그, 전략별 고유 조건만 적용)
   S1 추세 상승 (= 현재 상승 초입 패턴 A/B 그대로)
   S2 저점 반등·상승 전환 (신규)
   S3 박스권 돌파 (신규)
   공통 위험 상한: 과열(H16), 약한 마감(H18, H20 통합)
3단계 그룹 점수 (G1~G6 각 그룹 감점 1회, 가점은 기존 항목 유지)
   + 메타데이터 열 (selection_source = S1/S2/S3/fallback, repeat_days, data_notes)
```

레거시 추세 필터(H22~H26)는 어느 전략에도 일률 적용하지 않는다. 그 계산은 G1 그룹 점수와 진단 열로만 남긴다.

### 6.2 전략 정의 - 새 문턱을 만들지 않는다는 원칙

과최적화를 피하려고 **S2/S3의 조건은 코드에 이미 있는 판정 함수와 상수만 조합**하고, 값은 실험 전에 고정한다(7.4).
(이름 충돌 주의: 기존 "패턴 A/B 등급", r029 "B 전략(균형 진입)"과 구분하려고 S1/S2/S3로 부른다.)

| 전략 | 조건 (전부 기존 함수/상수) | 적용하지 않는 기존 조건 |
|---|---|---|
| S1 추세 상승 | `_pattern_assessment` A/B 그대로 (종가>MA20, MA20 비하락, MA120 -3% 초과, 장기선 위, 눌림 출발, 매수 신호는 점수로) | 레거시 5개 |
| S2 저점 반등 | (a) 52주 저가 대비 +30% 미만 또는 60일 고점 대비 -20% 이하 (기존 `near_52w_low_unconfirmed` 기준 재사용, -20%는 고정값) (b) 반전 신호: `_has_reversal_signal` 또는 `_has_volume_thrust_reversal` (c) 종가 > MA5 (d) 약한 마감 아님 (e) MA20 기울기 5일 >= -1% (하락 둔화, H12 문턱 재사용) | MA120 하락, 장기선 아래, 종가<=MA20, 레거시 5개, near_52w_low 감점 |
| S3 박스권 돌파 | (a) 직전 20거래일 고가-저가 폭 / 종가 <= 15% (박스) (b) 종가 > 직전 20거래일 최고 종가 (c) 당일 거래량 >= 20일 평균 x1.5 (`_has_volume_thrust_reversal`의 1.5배 재사용) (d) 약한 마감 아님 | flat_trend, box_range_no_progress, 눌림 출발 조건 |

S2의 -20%와 S3의 15%는 새 값이다. 이 둘은 실험 전에 고정하고, 실험 결과를 보고 바꾸지 않는다(바꾸면 새 버전으로 기록).

### 6.3 그룹 점수

- 그룹 감점 = 그 그룹 플래그 중 가장 무거운 것 하나(기본 -0.7, 기존 1.5 등급은 G6 소멸로 없어짐). 같은 그룹 플래그가 여러 개여도 1회.
- 3.3의 중복 감점(52주 고가, 전일 급등, 반복 선정)은 별도 감점 하나만 남기고 플래그 감점은 뺀다.
- 전략별로 해석이 다른 플래그는 전략 문맥에서 빼고 센다(S2에서 near_52w_low_unconfirmed, G1 일부는 감점하지 않음).
- 반복 선정은 점수가 아니라 정렬 규칙: 같은 점수대에서 반복 일수가 적은 종목 우선, 반복 4일 이상은 보충에서 제외(현행 효과와 비슷하게).
- low_score 바닥선은 V2에서 점수 분포가 바뀌므로 "V0의 적격 풀 크기를 유지하는 값"으로 한 번만 재보정하고 고정한다(2026-09-27 방식과 같음).

### 7.3 데이터와 누수 방지

- 포인트인타임 재스캔: 각 날짜는 그날까지의 daily.csv와 10초 파일만 사용(현재 g002 구조가 이미 대상일 폴더 기준).
  2026-11-11 재현과 같이 runtime/data/daily_history로 daily.csv가 짧은 과거 날짜를 보완한다(대상일 이후 행은 잘라서 사용).
- 종목군: 날짜 폴더의 g001 수집 목록 = 그날 실제 거래 가능 종목군(상장폐지 종목 포함). 현재 g004 유니버스로 과거를 돌리지 않는다.
- 기간: 10초 파일이 있는 2026-06-29 이후(약 95거래일)만 장중 ATR·매매 규칙 재현이 가능하다. 2018~ daily_backfill 장기 구간은
  현재 상장 종목만 있어 생존 편향이 있으므로 D+N 일봉 수익률 참고용으로만 쓰고 결론 근거로 쓰지 않는다.
- 미래 정보: 52주 고저는 KIS 서버값(수집 시점 값)이라 과거 재현에서는 그 날짜 폴더의 캐시만 쓴다. 섹터/관리종목 스냅샷도 같다.

### 7.4 과최적화 방지

- 모든 문턱은 기존 상수 재사용, 새 값(S2 -20%, S3 15%, low_score 재보정)은 실험 전에 이 문서에 고정.
- 버전 비교는 고정된 V0~V4만. 결과를 보고 문턱을 바꾸면 V3b처럼 새 버전으로 기록하고 검증 구간을 다시 쓰지 않는다.
- 채택 기준(사전 고정 제안): 검증 구간에서 V0 대비 (1) 매매 규칙 순손익 >= V0, (2) Profit Factor >= V0, (3) MDD가 V0의 1.2배 이내.
  종목 수 증가만으로는 채택하지 않는다.
