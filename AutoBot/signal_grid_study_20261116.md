## 2. 결과

### 2.1 기준선: 아무 조건 없이 매수

| 청산 | 순손익(1분봉 기준) | 비용 전 |
|---|---|---|
| 10분 | -0.37% | **-0.01%** |
| 30분 | -0.39% | -0.03% |
| 60분 | -0.42% | -0.06% |
| 당일 15:15 | -0.69% | **-0.34%** |
| 익절 1.5 / 손절 1 / 60분 | -0.41% | -0.05% |

- 단기 청산(10~60분)은 비용 전 손익이 0 근처다. **손실은 거의 비용(약 0.36%)에서 나온다.**
- 당일 보유는 비용 전에도 -0.34%다. 이 기간 이 종목들은 장중에 평균적으로 밀렸다.

### 2.2 분봉 (1·3·5분, 91거래일)

| 봉 | 규칙 x 청산 | 순손익 평균 > 0 | 학습·검증 모두 > 0 | 학습 상위 15개 -> 검증 양수 |
|---|---|---|---|---|
| 1분 | 2,868 | 0 | **0** | 0 / 15 (평균 -0.70%) |
| 3분 | 2,868 | 0 | **0** | 0 / 15 (평균 -0.84%) |
| 5분 | 2,868 | 3 | **0** | 0 / 15 (평균 -0.94%) |

- **비용 후 수익이 나는 단순 지표 조건은 없다.**
  - 손절·익절 청산을 넣어도, 신호 + 상태 2개 조합을 넣어도 마찬가지다.
  - 가장 좋은 조건의 순손익 평균도 +0.04%였고, 그것도 검증 구간에서 음수였다.
- 기준선보다 일관되게 나은 조건은 많다(학습·검증 모두 기준선 초과 1,170개).
  - 예: 5분 RSI 30 상향 + RSI 70 미만 + 당일 시가 위, 당일 청산 → 기준선 대비 학습 +0.27%p, 검증 +0.45%p
  - 그러나 절대 순손익은 -0.34%이고, 비용 전 손익은 0 근처(+0.02%)다.
- 즉 일부 신호는 "평균보다 덜 나쁜 시점"을 고르지만, **비용을 넘을 만큼 오르는 시점을 고르지는 못한다.**

### 2.3 틱봉 (60·120틱, 11거래일, 감시 종목)

최소 표본(60틱 60건, 120틱 40건) 이상이고, 학습·검증 비용 전 평균이 모두 0.4%를 넘는 조건 x 청산이 6개 있다.

|---|---|---|---|---|---|
| 60틱 | MACD 시그널 교차 + MACD 0선 돌파 + VWAP 돌파 | 당일 | 79 | +0.27% | 0.74 |

| 120틱 | MA 골든크로스 + BB 중간선 돌파 + 스토캐스틱 교차 | 당일 | 53 | +0.09% | 0.29 |

- 거래 수가 42~96건이다. 검증 구간은 4일뿐이고, t는 0.18~0.75로 통계적 근거가 없다.

- **탐색 결과로만 취급한다.** 공통점(MA 골든크로스 + 스토캐스틱 교차, 당일 보유)은 앞으로 쌓이는 틱 데이터에서 **조건을 고정해 둔 채** 확인할 후보다.

## 3. 결론

1. 분봉 91거래일에서 478개 조건 x 6개 청산 x 3개 봉 주기, 모두 **8,604개 조합 중 비용 후 학습·검증 평균이 모두 양수인 조합은 0개**다. 최소 표본 필터를 빼도 같다.
2. 단기(10~60분) 청산 손실은 대부분 비용이다. 비용 전 -0.007~-0.062%, 비용 후 -0.36~-0.42%로, 비용이 85~98%를 차지한다.
   당일 보유는 비용 전에도 -0.33~-0.34%다. 진입 신호의 비용 전 기대수익이 0 근처라서, 신호를 어떻게 조합해도 비용(왕복 약 0.36%)을 넘지 못한다. 앞선 연구(g026/g027, g030, g034)와 같은 결론이다.
3. 틱 11거래일에서는 전체 거래 수가 최소 표본 기준을 넘고, 학습·검증 비용 전 평균이 모두 0.4% 초과인 조합이 6개 있다.
   하지만 각각 42~96건이고, 전체 표본 비용 후 날짜 클러스터 t가 0.18~0.75라 탐색 결과에 그친다. 사전 지정 검증 후보로 둔다.
4. 이 결론은 이 조건 집합·기간·체결 모형 안에서만 유효하다. "단순 지표로는 절대 수익이 안 된다"는 일반화는 아니다.

## 4. 한계와 다음 확인

- 체결 모형은 다음 봉 시가 + 반 틱이다. 실제 지연, 스프레드, 시장 충격, 동시 보유·자본 한도는 반영하지 않았다.
- 틱 데이터는 11일, 검증 4일이라 검정력이 매우 낮다. 틱 수집을 계속해 최소 30거래일 이후 위 6개를 그대로 다시 검증한다(조건·청산·비용을 바꾸지 않음).
- 분봉 VWAP은 (고가+저가+종가)/3 x 거래량 근사다(캐시에 거래대금이 없음).
- 검증 구간은 이미 탐색에 쓰였다. 이 결과로 규칙을 새로 고르면 그 규칙에는 새 기간의 검증이 필요하다.
