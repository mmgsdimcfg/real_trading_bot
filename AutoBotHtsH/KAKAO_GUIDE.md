# 카카오톡으로 반등 알림 받기 — 연동 가이드

AutoBotHtsH의 바닥 반등 알림 요약을 본인 카카오톡 "나와의 채팅"으로 받기 위한 설정 순서입니다.
카카오 디벨로퍼스에 본인 앱을 하나 만들어야 합니다. 무료이고, 본인에게 보내는 메시지라 비즈니스 인증이나 검수는 필요 없습니다.

## 준비물

- 카카오 계정 (알림을 받을 카카오톡 계정)
- AutoBotHtsH 1.0.8_001 이상

## 1. 카카오 디벨로퍼스에서 할 일

### 1-1. 앱 만들기

1. <https://developers.kakao.com> 에 본인 카카오 계정으로 로그인합니다.
2. **앱** → **앱 추가**를 누릅니다.
3. 앱 이름과 회사명은 아무 값이나 넣어도 됩니다 (예: `AutoBotHtsH 알림`).

### 1-2. REST API 키와 리다이렉트 URI

1. **앱 → 플랫폼 키 → REST API 키**로 갑니다.
2. **REST API 키** 값을 복사해 둡니다.
   - 반드시 REST API 키여야 합니다. 네이티브 앱 키, JavaScript 키, 어드민 키는 안 됩니다.
3. 같은 화면의 **리다이렉트 URI**에 아래 주소를 등록합니다.

   ```
   http://localhost:5000/oauth
   ```

   - 이 주소로 실제 접속하지는 않습니다. 서버를 띄울 필요가 없습니다.
   - 앱에 입력하는 주소와 글자 하나까지 같아야 합니다 (끝의 `/`, http/https, 포트 포함).

### 1-3. 클라이언트 시크릿

같은 화면에서 **클라이언트 시크릿** 상태를 확인합니다.

- "사용함"이면 그 값을 복사해 둡니다.
- "사용 안 함"이면 건너뜁니다.

### 1-4. 카카오 로그인 켜기

**카카오 로그인 → 사용 설정**에서 상태를 **ON**으로 바꿉니다.

### 1-5. 동의항목 설정

**카카오 로그인 → 동의항목**에서 **카카오톡 메시지 전송 (talk_message)** 을 **선택 동의**로 설정합니다.

### 1-6. (선택) 링크 도메인 등록

메시지 아래의 `종목 보기` 버튼이 열리게 하려면 **앱 → 제품 링크 관리 → 웹 도메인**에 아래 주소를 등록합니다.

```
https://m.stock.naver.com
```

등록하지 않아도 메시지는 옵니다. 버튼만 동작하지 않습니다.

## 2. AutoBotHtsH에서 할 일

1. ☰ → **반등 감시 설정** → **카카오톡** 탭을 엽니다.
2. **REST API 키**를 붙여 넣습니다. 클라이언트 시크릿이 "사용함"이었다면 그 값도 넣습니다.
3. **리다이렉트 URI**가 콘솔에 등록한 주소와 같은지 확인합니다.
4. **앱 정보 저장**을 누릅니다.
5. **카카오 로그인**을 누릅니다. 로그인 창이 뜨면 본인 계정으로 로그인하고, 동의 화면에서 **카카오톡 메시지 전송**을 체크한 뒤 동의합니다.
6. **테스트 메시지 보내기**를 누르고, 카카오톡 "나와의 채팅"에 메시지가 왔는지 확인합니다.
7. **알림을 내 카카오톡으로 보내기**를 체크하고 창 아래의 **저장**을 누릅니다.

이후에는 반등 알림 팝업이 뜰 때마다 요약 1건이 카카오톡으로 옵니다.

## 3. 받게 되는 메시지 예시

```
[바닥 반등 초입] 한국피아이엠(448900)
14:55 봉 · 38,500원 (-2.41%) · 가점 3점
RSI 53.3/48.8 · MACD -40.3/-61.7
DI 32.2/12.6 · ADX 35.6 · 각도 14.6°
VWAP -3.29% · 급락 14:33 (-2.7%)
가점: ADX 반등, 볼린저, 거래량 감소
```

카카오 기본 템플릿 한도인 200자 이내로 보냅니다.

## 4. 오류가 날 때

오류가 나면 카카오톡 탭에 오류 코드와 안내 문구가 표시됩니다.

| 오류 | 원인 | 해결 |
|---|---|---|
| KOE004 | 카카오 로그인이 꺼져 있음 | 1-4 |
| KOE006 | 리다이렉트 URI가 등록 값과 다름 | 1-2. 끝의 `/`, http/https, 포트까지 같아야 함 |
| KOE010 | 클라이언트 시크릿 불일치 | 1-3. 켜져 있으면 값을 입력, 꺼져 있으면 `시크릿 지우기` |
| KOE101 | REST API 키가 아닌 키를 넣음 | 1-2 |
| KOE205 | talk_message 동의항목 미설정 | 1-5 |
| KOE303 | 로그인 때와 리다이렉트 URI가 다름 | 주소를 바꿨다면 `다시 로그인` |
| KOE320 | 인가 코드 만료 또는 재사용 | `다시 로그인` |
| -402 | 로그인 때 메시지 전송에 동의하지 않음 | `다시 로그인` 후 동의 화면에서 체크 |
| KOE322, -401 | 로그인 만료 | `다시 로그인` |

## 5. 알아 둘 점

- **저장 위치**: 키, 시크릿, 로그인 토큰은 `%APPDATA%\autobothtsh\rebound\kakao.json`에 이 PC의 Windows 계정으로 암호화해 저장합니다. 다른 PC로 복사하면 쓸 수 없으므로 그 PC에서 다시 설정해야 합니다.
- **로그인 유지 기간**: 약 2개월이며 메시지를 보낼 때마다 자동으로 연장됩니다. 2개월 넘게 알림이 한 번도 없었다면 `다시 로그인`이 필요합니다.
- **전송 결과 확인**: 설정 창의 히스토리 탭에서 각 알림 옆의 `톡` 표시로 확인합니다 (초록 = 전송됨, 빨강 = 실패와 이유).
- **알림 소리**: 카카오톡에서 "나와의 채팅" 알림이 꺼져 있으면 메시지가 소리 없이 쌓이기만 합니다.
- **콘솔 메뉴 이름**: 카카오가 콘솔 화면을 개편하면 메뉴 이름이나 위치가 달라질 수 있습니다. 찾는 항목은 REST API 키, 리다이렉트 URI, 클라이언트 시크릿, 카카오 로그인 사용 설정, talk_message 동의항목 다섯 가지입니다.
